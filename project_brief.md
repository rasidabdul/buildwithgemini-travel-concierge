# My agent: Travel Concierge

**One-liner**: A conversational agent that helps travelers discover, plan, and manage personalized travel itineraries with a catalog of destinations, activities, and bookings.

## Tool Coverage
- **Memory**: Remembers traveler preferences (budget level, preferred travel style, dietary restrictions, favorite airlines/hotel types, past visited locations).
- **Tools**: Search destination/hotel/activity catalog, add activity to trip itinerary, check weather forecasts for trip dates.
- **Catalog/UI**: Destination recommendation cards, hotel listings, and structured daily itinerary tables (rendered via A2UI).
- **Image gen**: Generates scenic destination previews, custom postcards, and travel moodboards on demand.
- **Sandbox**: Calculates budget splits across travel categories, currency conversions, and daily schedule duration math.

## Recommendations & Stretch Features
- **Core Features**: Memory, Firestore storage, function tools, image generation, A2UI cards/tables.
- **Agent-Specific / Stretch**: Google Maps API integration, Cloud Trace observability, and video previews with Omni.
